# Reparto: Print-on-Demand / Self-Publishing

Canale di vendita diverso dal blog: ricerca su Amazon/marketplace invece che su Google. Contenuti a basso contenuto testuale ma utili (planner, tracker), pubblicati senza magazzino fisico (KDP per ebook/libri stampabili, Printful/Redbubble per design). Trattato come esperimento a basso impegno per diversificare, non come motore principale.

## File
- `backlog.csv` — elenco prodotti pianificati
- `products/<slug>/outline.md` — struttura/contenuto del prodotto
- `data/accounts-todo.md` — account necessari

## Attenzione
Questo mercato è molto affollato. Il reparto va rivalutato dopo 6-8 settimane: se zero segnali, si mette in pausa e si concentra il tempo altrove (vedi regole in `company/ORG.md`).
