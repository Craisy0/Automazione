# AI Tool Stack Checklist for Freelancers

*A one-page, no-nonsense checklist to help you pick and set up the right AI/automation tools for your solo business — without wasting a weekend testing twelve apps you'll never use.*

## How to use this checklist

Go through each section in order. Don't install everything at once — pick one tool per section, use it for two weeks, then move to the next.

## 1. Workspace (pick one)
- [ ] Notion — best if your work is knowledge-heavy (consulting, coaching, content)
- [ ] ClickUp — best if you juggle several projects with hard deadlines
- [ ] Setup time budget: 2-3 hours to build your first client tracker

## 2. Automation (pick one)
- [ ] Zapier — easiest to start with, huge app library
- [ ] Make (Integromat) — more powerful, steeper learning curve
- [ ] First automation to build: new client intake → workspace record → welcome email

## 3. Calendar & time
- [ ] Reclaim.ai or similar AI scheduling assistant
- [ ] Block "deep work" time before you accept new recurring meetings

## 4. Content / marketing (only if you publish regularly)
- [ ] Frase.io or similar for research-backed writing
- [ ] Beehiiv or similar if you're building a newsletter

## 5. Website (only if you don't have one yet)
- [ ] Framer or similar no-code builder
- [ ] Minimum viable pages: home, services, contact — nothing more for now

## 6. Monthly review (recurring)
- [ ] Which tool did you actually use every week this month?
- [ ] Which one did you forget you were paying for? Cancel it.
- [ ] Is there one manual task you did 3+ times this month that could be automated?

## A note on cost

Most of these tools have a usable free tier for a single user. Don't pay for anything until the free tier genuinely limits you — for a one-person business, that often takes longer than you'd expect.
